# 博士套磁信

把邮件写成研究经历的短预告：让教授迅速看清申请者是谁、亲自做过什么、何时能入学，愿意看 CV 或继续交流。不要把一封邮件的目标设成直接拿到 offer。

将方法作为一位教授的经验，主要适用美国博士初次联系。其他地区、学科和具体招生公告应按实际要求调整；不要宣称这是大学官方规则。需要追溯原意或处理争议时，读取 [来源与取舍](references/source-notes.md)。

## 先提炼事实

1. 读取用户给出的旧信、CV、科研说明和导师要求；已有信息不要反复询问。若只有旧信，先完成改写，不强制索取 CV。
2. 抽取姓名、学位与专业、学校及必要的国家信息、预计毕业时间、目标入学时间、收件人姓名、研究方向。将毕业时间与入学时间分开，不互相推断。GPA 仅在已提供、量表明确且有说服力时保留。
3. 选一个最有说服力且与目标相关的项目，提炼一至两个真实贡献；只有确实增加信息时才补第二个项目。按“研究问题 → 我亲自采取的行动与方法 → 已知结果或体现的能力”写，结果缺失时不要补造。
4. 区分个人任务与团队成果；区分已发表、已接收、投稿中、预印本和未发表项目。不要将参与写成主导，将提交写成发表，将探索性结果写成已验证结论。没有论文时用实际研究工作证明能力，不添加道歉。
5. 按用户提供的要求写。若需要补查导师网页或用户明确要求查阅，核查官网、招生公告或论文原文，只检索会改变信件内容的事实。不要从旧论文推断对方当前项目、经费或招生名额。
6. 缺少信息时用 [Expected graduation]、[Intended start term] 等清晰占位符先出一版，并在邮件外列出必要待填项。遇到矛盾不要自行选一个版本。不把一般背景或记忆中的个人信息未经确认地填成当前申请事实。

## 默认写成三段

默认英文正文约 150–200 词、三个短段落，目标是便于快速阅读。这个词数是实现上的参考，不是原教授提出的硬性门槛；信息少时更短，有明确要求时调整。解释默认用中文，邮件语言遵从用户要求。

- **主题与称呼**：使用 “PhD inquiry — [Intended start term] — [Research area]”，不清楚的部分删去或标注。对于明确是教授的收件人，使用 “Dear Professor [Surname],”；用户或收件人明确的称谓优先。不堆叠职称。
- **第一段，背景与时间**：直接写当前学位、学校、预计毕业时间及申请意图；GPA 只作为可选的简短信号。礼貌开场可省略。
- **第二段，研究贡献**：用两至四句说明一个具体研究问题及自己做过的一至两项工作。使用清楚的动作和方法，避免 passionate、hard-working、extensive experience 等无证据自评。论文状态只在有用时简短补充，不以论文总数开场。
- **第三段，下一步**：说明目标入学时间，询问是否考虑招收该届博士生；表达愿意简短交流。只有用户确认会附 CV 或已经提供该附件安排时，才写 “I have attached my CV”。签名用姓名。

删去长篇动机、成长故事、对教授工作的复述和泛泛赞美。若一条真实连接能帮助对方判断，把“自己的具体经验如何支持相关研究问题”写成至多一句；不要声称完美匹配，不强行加入论文名称或献上未经请求的完整 proposal。

默认附件安排只需 CV；招生广告有要求时遵从。把细节放在 CV，不在正文罗列全部项目、论文和课程。转介请求仅在用户希望扩大联系范围且语气自然时加入，不作为固定结尾。

需要起草骨架时读取 [英文骨架](assets/email-template.txt)，按事实取舍，避免机械填满每个位置。需要可复制到其他模型的提示词时直接给出 [独立提示词](assets/reusable-prompt.txt)。

## 跟进邮件

仅在用户需要 follow-up 时使用。先看原邮件、发送时间、回复和对方要求。

- 无回复约一周后，可在同一线程简短跟进；已有自动回复、招生时间安排或明确不接收套磁信时，遵从这些信息。
- 默认只写当前需要的一封，约 40–70 词：提醒此前联系、重申入学时间或一项有用更新、给出一个简短请求。无需再次粘贴整封首信。
- 原语料认为最多三次可以接受，将其视为个人容忍度参考，不设成必须跟进三次的目标。避免连续催促；明确拒绝或停止联系要求应结束跟进。
- 不把未回复解读为能力不足，也不保证跟进一定得到回复。

## 交付与检查

默认交付一个 Subject 和一封可复制的邮件，再用至多三条中文说明关键改动。存在待填或待核实事实时另列必要清单；用户要求只给正文时省去说明，不隐藏占位符。

交付前检查：

- 能否迅速找到身份、毕业时间、入学时间、个人贡献和下一步？
- 是否至少有一项具体工作，且没有虚构结果、GPA、作者身份、发表状态或导师招生情况？
- 是否删除重复、自评、过度恭维和把团队成绩归给个人的措辞？
- 是否与已给出的 CV 一致，且真实附件安排与正文表述一致？
- 是否遵从该导师的明确要求，所有未知项都有标识？

邮件写作本身不包含发送或安排提醒；只在用户另有明确请求时执行这些动作。
