# 来源与取舍

## 来源边界

方法提炼自一位招生教授关于博士套磁的讲解，涵盖目标、论文、邮件结构、匹配与附件及 follow-up。现有整理材料未包含可公开核验的讲者姓名或原始链接，因此不作大学背书或官方政策的归属声明。本仓库发布的是提炼后的方法、提示词与原创英文骨架，不包含录音或逐字转写。

将内容视为个人经验。原材料开头谈到北美和香港，后续将主要写法限定到美国；不要泛化为所有地区、学科或大学的招生政策。转写中的“套瓷”“陶瓷”“告磁”等统一理解为“套磁”，不要据含混转写猜补示例细节。

## 保留的核心

1. 目标是激发兴趣、促使阅读 CV 和进一步交流；信任要逐步建立。
2. 邮件要短，关键背景和亮点容易定位；原语料强调读信不应超过约一分钟。
3. 写清学校、学历、必要的国家信息、毕业时间和可以开始博士的时间。
4. 用真实工作显示能力，尤其是写作、文献整理、数据分析和实验设计等个人贡献；不要拿论文篇数代替贡献。
5. 没有已发表论文也可以描述做过的研究；不要因缺少论文自动写成道歉或自我贬低。
6. 邮件是预告，详细经历放在 CV；一般只附 CV，明确要求优先。
7. 没有回复不自动等于能力不足；一周左右的简短跟进是原教授提出的做法。

## 有条件采用的观点

| 原语料观点 | 本 Skill 的处理 |
| --- | --- |
| 主要凭学校和 GPA 表现能力 | 写清背景；GPA 作为可选证据，不把学校声望等同于科研能力。 |
| 硕士已有四篇论文可能是 red flag | 保留“追问真实贡献”的理由；不设置篇数惩罚阈值。 |
| matching 段完全没有必要 | 删除重复介绍教授工作的长段；允许一句真实、具体的研究连接。 |
| 统一称 Professor | 对明确是教授的收件人默认采用；尊重已知称谓。 |
| 可请求转发给其他同事 | 保留为可选句，不默认增加对方负担。 |
| 最多跟进三次不会烦 | 将三次视为个人观点；不保证收件人反应，不自动写三封催信。 |
| 跟进会让教授愧疚并回复 | 不采用这一心理推断，不以施压为写作策略。 |

## 实现上的补充

以下是为快速复用添加的操作规则，不是教授的原话：默认三段、约 150–200 个英文词；主题加入入学时间和研究方向以便识别；缺项用占位符先起草；严格保留事实与论文状态；默认只出一版，并给出少量关键修改说明。

这份语料没有提供标准英文邮件原文、CV 方法或 Zoom 面试方法。英文骨架为依据原则编写的模板，不冒充原教授逐字模板；后两项不包含在本 Skill 范围内。
